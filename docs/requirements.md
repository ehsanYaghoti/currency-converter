# Requirements
A currency converter app helps users understand how much money in one currency is worth when exchanged into another currency.


## MVP Features

### 1.Currency selection

User should be able to:
- Select a source currency
- Select a target currency
- Swap currencies

requirements :
1. Searchable dropdown
2. Currency name
3. Currency code
4. Currency symbol
5. Country flag


### 2. Amount Input

Features:

1. Numeric input
2. Decimal support
3. Thousand separators

Handle:

1. Empty input
2. Very large numbers
3. Negative values

### 3. Real-Time Conversion

.Convert while typing

## User Experience Features

1. currency Swap Button
2. Recent Currency Pairs
3. Favorite Currencies
4. Currency Search

## Technical Features

1. Loading States

2. Error Handling
